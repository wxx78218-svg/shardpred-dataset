# shardpred-dataset
Public dataset for shard pressure prediction and dynamic blockchain sharding experiments.
## Dataset Download

Due to GitHub's web upload size limit, the dataset is distributed
as three ZIP archives:

- `shard_workload_dataset_part1.zip`
- `shard_workload_dataset_part2.zip`
- `shard_workload_dataset_part3.zip`

Download all three archives before using the dataset.

Each archive contains a portion of the shard workload dataset.
After extraction, place all CSV files in the same directory.
